# ПРАКТИЧЕСКАЯ РАБОТА №1
**Тема:** Реализация базового WebAR-сценария с использованием `<model-viewer>`

### 1. Требования к работе:
* Создать HTML-страницу.
* Разместить 3D-модель в AR с помощью тега `<model-viewer>`.
* Указать режимы AR (`ar`, `ar-modes="webxr scene-viewer quick-look"`).
* Настроить поддержку Quick Look (iOS) и Scene Viewer (Android).
* Подготовить модель в форматах glTF/GLB и USDZ.
* Настроить HDRI-карты для корректного освещения модели.

### 2. Описание выполнения работы:
1. **Подготовка 3D-модели:**
   Для выполнения задания была выбрана высокодетализированная PBR-модель скафандра космонавта (`Astronaut.glb`) в формате бинарного glTF 2.0. Для обеспечения кроссплатформенности и поддержки устройств на базе iOS (iPhone/iPad) была также подготовлена модель в формате `.usdz` (`Astronaut.usdz`).
2. **Разработка HTML-разметки и интеграция `<model-viewer>`:**
   Создан файл `index.html`, куда через CDN подключена библиотека Google `@google/model-viewer`.
   В коде реализованы следующие параметры:
   * `src="assets/Astronaut.glb"` и `ios-src="assets/Astronaut.usdz"` — кроссплатформенное подключение модели для систем Android и iOS.
   * `ar` и `ar-modes="webxr scene-viewer quick-look"` — настроены режимы дополненной реальности для запуска нативных системных просмотрщиков Scene Viewer и Quick Look.
   * `camera-controls` — добавлена возможность интерактивного вращения и масштабирования объекта жестами на странице.
   * `environment-image="assets/aircraft_workshop_01_1k.hdr"` — подключена реалистичная HDRI-карта окружения для физически корректного расчета отражений (в частности, на зеркальном стекле шлема скафандра) и освещения материалов модели.
   * `shadow-intensity="1.2"` — настроена четкая тень под ногами модели при размещении на горизонтальной плоскости.
   * Внедрен кастомный слот кнопки активации режима AR (`slot="ar-button"`).

### 3. Листинг кода (`task1-model-viewer/index.html`):
```html
<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>WebAR Задание 1</title>
    <!-- Подключаем библиотеку model-viewer от Google -->
    <script type="module" src="https://ajax.googleapis.com/ajax/libs/model-viewer/3.5.0/model-viewer.min.js"></script>
    <style>
        body {
            margin: 0;
            padding: 0;
            width: 100vw;
            height: 100vh;
        }
        model-viewer {
            width: 100%;
            height: 100%;
        }
    </style>
</head>
<body>
    <!-- Компонент для отображения 3D и AR -->
    <model-viewer src="assets/Astronaut.glb"
                  ios-src="assets/Astronaut.usdz"
                  ar
                  ar-modes="webxr scene-viewer quick-look"
                  camera-controls
                  environment-image="assets/aircraft_workshop_01_1k.hdr"
                  shadow-intensity="1">
        <!-- Кнопка для запуска AR -->
        <button slot="ar-button" style="position: absolute; bottom: 30px; left: 50%; transform: translateX(-50%); padding: 12px 24px; font-size: 16px; border-radius: 8px;">
            Открыть в AR
        </button>
    </model-viewer>
</body>
</html>
```

### 4. Развертывание и тестирование:
Поскольку работа с камерой и WebXR требует обязательного защищенного протокола, проект был запущен с локального сервера с настроенным HTTPS-сертификатом (`python server.py`).
Тестирование было проведено на реальном смартфоне:
* В обычном режиме страница корректно отображает 3D-модель с HDRI-освещением, реалистичными бликами на материалах и тенями.
* При нажатии кнопки «Открыть в AR» устройство запускает нативный режим дополненной реальности (Scene Viewer на Android / Quick Look на iOS), позволяя спозиционировать космонавта на полу или столе в масштабе 1:1.

# ПРАКТИЧЕСКАЯ РАБОТА №2
**Тема:** Внедрение трекинга изображений с помощью MindAR (A-Frame)

### 1. Требования к работе:
* Создать HTML-страницу с использованием библиотек A-Frame и MindAR.
* Подготовить изображение-маркер и скомпилировать его в формат `targets.mind` с помощью утилиты MindAR.
* Интегрировать на страницу компонент image-tracker для распознавания маркера.
* Разместить 3D-модель (в формате glTF) так, чтобы она появлялась при наведении камеры на выбранное изображение.
* Настроить базовые параметры освещения сцены для корректного отображения модели.

### 2. Описание выполнения работы:
1. **Подготовка 3D-модели и изображения-маркера:**
   Для выполнения работы было подготовлено изображение-маркер (`card.png`), содержащее высокую концентрацию контрастных углов, геометрических элементов и надписей, необходимых для стабильного распознавания алгоритмами компьютерного зрения.
   С помощью компилятора MindAR (`targets compiler`) исходное изображение было скомпилировано в бинарный файл дескрипторов опорных точек `targets.mind`.
   В качестве 3D-объекта была использована оптимизированная модель космонавта (`model.glb`).
2. **Разработка HTML-сцены и настройка трекинга:**
   Создан файл `index.html`, куда через CDN подключены библиотеки A-Frame (v1.4.2/1.5.0) и модуль трекинга изображений `mindar-image-aframe.prod.js`.
   В коде реализованы следующие элементы:
   * В теге `<a-scene>` с помощью атрибута `mindar-image="imageTargetSrc: ./assets/targets.mind;"` настроена инициализация AR-движка и указан путь к таргет-файлу.
   * В секции `<a-assets>` настроена предзагрузка 3D-модели через тег `<a-asset-item>`.
   * В компонент `<a-entity mindar-image-target="targetIndex: 0">` помещена модель `<a-gltf-model>`, что обеспечивает ее фиксацию в пространстве над маркером в момент распознавания камерой.
   * Внутри сцены настроены источники света (`ambient` и `directional`), обеспечивающие корректную цветопередачу и объемное освещение полигонов модели.

### 3. Листинг кода (`task2-mindar/index.html`):
```html
<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>WebAR Задание 2 - Image Tracking</title>
    <!-- Подключение библиотек A-Frame и MindAR Image Tracking через CDN -->
    <script src="https://aframe.io/releases/1.4.2/aframe.min.js"></script>
    <script src="https://cdn.jsdelivr.net/npm/mind-ar@1.2.5/dist/mindar-image-aframe.prod.js"></script>
    <style>
        body { margin: 0; overflow: hidden; }
    </style>
</head>
<body>
    <!-- Инициализация AR-сцены и привязка файла маркера -->
    <a-scene mindar-image="imageTargetSrc: ./assets/targets.mind;"
             color-space="sRGB"
             renderer="colorManagement: true, physicallyCorrectLights"
             vr-mode-ui="enabled: false"
             device-orientation-permission-ui="enabled: false">
             
        <a-assets>
            <!-- Предзагрузка 3D-модели -->
            <a-asset-item id="modelAsset" src="./assets/model.glb"></a-asset-item>
        </a-assets>

        <a-camera position="0 0 0" look-controls="enabled: false"></a-camera>

        <!-- Трекер маркера (targetIndex: 0) -->
        <a-entity mindar-image-target="targetIndex: 0">
            <!-- Освещение сцены -->
            <a-light type="ambient" color="#FFF" intensity="0.8"></a-light>
            <a-light type="directional" position="1 2 1" intensity="1.0"></a-light>

            <!-- Отображаемая 3D-модель -->
            <a-gltf-model 
                src="#modelAsset"
                rotation="0 0 0"
                position="0 -0.4 0.1"
                scale="0.18 0.18 0.18">
            </a-gltf-model>
        </a-entity>
    </a-scene>
</body>
</html>
```

### 4. Деплой и тестирование работы:
Файлы проекта были развернуты на веб-сервере с протоколом HTTPS.
Тестирование проводилось со смартфона:
* При открытии веб-страницы запрашивается и активируется видеопоток с камеры смартфона.
* При наведении объектива на плоское изображение-маркер библиотека фиксирует опорные точки и стабильно отображает 3D-модель точно поверх маркера.
* При изменении угла обзора и расстояния модель сохраняет позиционирование относительно плоскости маркера без срывов трекинга.

# ПРАКТИЧЕСКАЯ РАБОТА №3
**Тема:** AR-маска или эффект с использованием MindAR Face Tracking

### 1. Требования к работе:
* Создание WebAR-сцены.
* Использование библиотеки MindAR (режим Face Tracking на базе нейросети MediaPipe).
* Накладывание 3D-маски или фильтра (очки, головной убор, маска) при обнаружении лица пользователя.
* Настройка масштаба, позиции и привязки к ключевым точкам лица (`anchorIndex`).
* Обеспечение стабильности трекинга при движении головы.

### 2. Описание выполнения работы:
1. **Подготовка 3D-модели:**
   Для наложения эффекта на лицо была подобрана легкая 3D-модель солнцезащитных очков (`glasses.gltf`) со стеклами и оправой.
2. **Разработка HTML-сцены и привязка к лицу:**
   Создана веб-страница с подключением библиотек A-Frame и MindAR Face Tracking через CDN (`mindar-face-aframe.prod.js`).
   В теге `<a-scene>` инициализирован модуль `mindar-face`.
   С помощью `<a-assets>` настроена предзагрузка 3D-модели очков.
   Настроено базовое фоновое и направленное освещение сцены (`ambient` и `directional light`) для реалистичного отображения материалов модели и бликов на линзах.
   В компоненте `<a-entity mindar-face-target="anchorIndex: 168">` настроена привязка к ключевой точке переносицы (индекс 168 в топологии лицевой сетки MediaPipe FaceMesh), а также откалиброваны координаты положения (`position="0 0 -0.05"`) и масштаб (`scale="0.01 0.01 0.01"`).

### 3. Листинг кода (`task3-face-tracking/index.html`):
```html
<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>WebAR Задание 3 - AR Очки</title>
    <!-- Подключаем A-Frame и MindAR Face Tracking -->
    <script src="https://aframe.io/releases/1.4.2/aframe.min.js"></script>
    <script src="https://cdn.jsdelivr.net/npm/mind-ar@1.2.5/dist/mindar-face-aframe.prod.js"></script>
    <style>
        body { margin: 0; overflow: hidden; }
    </style>
</head>
<body>
    <!-- Инициализируем сцену с Face Tracking -->
    <a-scene mindar-face vr-mode-ui="enabled: false" device-orientation-permission-ui="enabled: false">
        <a-assets>
            <!-- Загружаем 3D-модель очков -->
            <a-asset-item id="glassesModel" src="./assets/glasses.gltf"></a-asset-item>
        </a-assets>

        <a-camera active="false" position="0 0 0"></a-camera>

        <!-- Мягкое освещение, чтобы модель не была темной -->
        <a-light type="ambient" color="#FFF" intensity="0.9"></a-light>
        <a-light type="directional" position="0 1.5 1.5" intensity="1.2"></a-light>

        <!-- ИНДЕКС 168 — переносица между глазами (идеально для очков) -->
        <a-entity mindar-face-target="anchorIndex: 168">
            <!-- Базовые настройки масштаба и смещения -->
            <a-gltf-model 
                src="#glassesModel" 
                rotation="0 0 0" 
                position="0 0 -0.05" 
                scale="0.01 0.01 0.01">
            </a-gltf-model>
        </a-entity>
    </a-scene>
</body>
</html>
```

### 4. Развертывание и тестирование:
Файлы проекта были развернуты на локальном HTTPS-сервере. Было проведено тестирование на мобильном устройстве через фронтальную камеру:
* Нейросеть MediaPipe в реальном времени определяет геометрию лица пользователя.
* 3D-модель очков надежно фиксируется на переносице и следует за всеми поворотами и наклонами головы без задержек.
